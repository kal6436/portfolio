# Guide of Frequent Punctuation in Code
| Symbol | Name | What it Does | Example |
| :---: | :---: | :---: | :---: |
| < > | Angle Brackets | Used to open and close HTML tags | <p>... </p> |
| > | Greater Than | Comparison operator | 
| < | Less Than | Comparison operator | 
| () | Parentheses | Groups expressions, used for functions | url(image.png) |
| { } | Curly Braces | Wraps CSS rules | h1 { color: blue;} |
| ~ | Tilde | Indicates your home folder | 
| / | Forward Slash | Used to close HTML tags, can also appear in file paths/urls | </p>... |
| \ | Backslash | Used to separate Windows file paths and escape | 
| - | Hyphen | Subtraction operator, used in CSS tag names | background-color |
| . | Period | Used to select a class in CSS | .body {} |
| : | Colon | Used in CSS to assign a value to a property | color: red; |
| , | Comma | Separate items in lists or function arguments |
